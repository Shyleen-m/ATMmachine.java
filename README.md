ATM Banking System Simulation (Java)
Overview

This project is a Java-based ATM banking system simulation designed to demonstrate core banking operations and software engineering principles. The application supports features such as user authentication, transaction tracking, data persistence, and ATM resource management.

Features
User authentication and account access
Transaction processing and history tracking
Persistent data storage
ATM paper and ink resource management
Object-oriented architecture and modular design
Improved Version 2 with cleaner dependency management and enhanced scalability
Technologies Used
Java
Object-Oriented Programming (OOP)
Purpose

This project was developed as an educational simulation to model real-world banking system functionality while applying software engineering best practices.
